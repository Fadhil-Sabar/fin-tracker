## Varian 3: Earthy Material 🌿

### Design stance
**Hybrid terbaik.** Material Design 3 yang colorful dengan earth tones. Paling mirip struktur existing code — jadi paling gampang diimplement. Tapi vibe-nya beda total.

### Key choices
- **Palette lengkap:** Terracotta, Sage, Brick, Copper + beige — komplit
- **Background:** Subtle radial gradient tones (terracotta + sage) — kedalaman tanpa clutter
- **Brand icon:** Gradient terracotta→copper, hover rotasi — playful
- **Cards:** Top accent bar (bukan border-left) — lebih modern
- **Charts:** Gradien bars (income green gradient, expense red gradient)
- **Top bar:** Ada tombol Filter & +Tambah — lebih actionable
- **Table:** Hover row effect — interactive feedback
- **Responsive:** Grid collapse ke 2 kolom di tablet — production-ready

### Trade-offs
- **Strong at:** Paling kaya secara visual, paling "premium", paling gampang migrasi dari existing code
- **Weak at:** Paling kompleks — butuh effort lebih untuk implement

### Best for
"Sweet spot" antara hangat dan fungsional. Ini yang paling gue rekomendasiin.
